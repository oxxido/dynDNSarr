# ADR-0002 — Python 3.11 como versión mínima

**Fecha:** 2026-10-14

## Contexto

[architecture.md](../architecture.md) §2 fijaba Python 3.12+ "verificando disponibilidad en la Raspberry". La Raspberry destino trae Python 3.11.2 y el Agent se ejecuta nativo (venv + systemd), por lo que usa el Python del sistema.

## Decisión

Versión mínima **3.11**. El Agent se instala con el Python del sistema; no se añaden `pyenv`, `uv` ni compilaciones propias en la Pi. El desarrollo local usa 3.12 y la CI prueba 3.11 y 3.12 para detectar el uso accidental de funciones de 3.12. El Hub corre en Docker con su propio Python (3.12) y no depende de la Pi.

## Consecuencias

- `requires-python = ">=3.11"` en los paquetes.
- Mientras la Pi no actualice su Python, no se puede usar nada exclusivo de 3.12 en código compartido o del Agent.
- El §15 de la arquitectura (prompt de arranque) conserva "3.12+" por ser el texto histórico del handoff; prevalece este ADR.
